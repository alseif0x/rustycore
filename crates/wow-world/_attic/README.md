# Archived MapManager prototype

This directory contains files from an abandoned MapManager migration. The Rust prototypes have a `.rs.txt` suffix. Historical shell scripts can change files if executed. The live runtime and its owners are documented in the [architecture guide](../../../docs/architecture/ownership-and-boundaries.md).

The [original inventory](https://github.com/alseif0x/rustycore/blob/5fe18d391a4adb43e72a764f9235d855761fdf24/crates/wow-world/_attic/README.md) identifies the attempted bridges, file moves and the three retired planning documents. Consult it when tracing the prototype's provenance.
