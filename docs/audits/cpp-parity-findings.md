# C++ parity findings and evidence

The June–September WotLK comparisons examined named Rust operations against specific C++ implementations. The [original findings, test identities and source anchors](https://github.com/alseif0x/rustycore/blob/5fe18d391a4adb43e72a764f9235d855761fdf24/docs/audits/cpp-parity-findings.md) are frozen at their reviewed revisions. The [source locator](https://github.com/alseif0x/rustycore/blob/5fe18d391a4adb43e72a764f9235d855761fdf24/docs/audits/cpp-parity-audit-index.md) and [checklist](https://github.com/alseif0x/rustycore/blob/5fe18d391a4adb43e72a764f9235d855761fdf24/docs/audits/cpp-parity-checklist.md) belong to that same campaign.

For an active investigation, start with the [defect register](../migration/EXISTING-CODE-DEFECTS.md) and [#65](https://github.com/alseif0x/rustycore/issues/65). Verify the current production owner, versioned C++ path and capture requirement on the target branch. The archived IDs are stable lookup keys for the underlying reports.
