# World server shutdown

The shutdown code refers here for the 3.4.3 reference sequence. After `World::KickAll`, C++ runs `sWorld->UpdateSessions(1)` before network and database cleanup. The audited Rust implementation queued shutdown markers to session tasks and waited for active sessions to unregister. The historical audit left the global session update, erase and deletion pass as a separate obligation. Recheck the current shutdown owner and tests before changing this sequence.
